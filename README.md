### Функциональность

- Моделирование хода луча в сферической капле

# Моделирование радуги

Дисперсия и многократное преломление света в каплях воды — интерактивный лендинг для лабораторной работы по физике (ИТМО,).

---

## О проекте

Радуга — одно из самых красивых оптических явлений природы. Она возникает, когда солнечный свет преломляется, отражается и диспергирует в миллионах дождевых капель.

Модель воспроизводит этот процесс на уровне геометрической оптики: от единичного луча до полной картины распределения цветов. Рассматриваются первичная радуга (одно внутреннее отражение, угловой радиус ≈ 42°) и вторичная радуга (два отражения, радиус ≈ 51°). Также исследуется альтернативная геометрия — дисперсия в стеклянной призме треугольного сечения.

**Цель проекта** — дать пользователю возможность самостоятельно исследовать физику радуги: менять длину волны, показатель преломления, геометрию капли и призмы, наблюдать как меняются углы отклонения, интенсивность и распределение цветов в реальном времени.

## Функционал

### 1. Ход луча в сферической капле (`RayTraceDemo`)

Геометрическая оптика внутри сферической капли воды. Луч проходит через границу раздела воздух–вода, преломляется по закону Снеллиуса, испытывает внутреннее отражение от задней стенки и выходит обратно.

**Интерактивные элементы:**
- Ползунок длины волны λ (380–780 нм)
- Ползунок прицельного параметра h/R (0.01–0.99) — точка входа луча относительно центра капли
- Ручной ввод коэффициентов Коши A, B, C
- Кнопки пресетов цвета (красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый)
- Кнопка сброса коэффициентов на воду

**Вкладки:**
- **2D-модель** — SVG-схема: капля, входящий луч (белый пунктир), преломлённый луч (цветной), отражённый луч, выходящий луч. Подписаны точки входа, отражения, выхода, дуга угла радуги θ
- **3D-вид** — Three.js-сцена: полупрозрачная сфера, линии лучей (входящий/преломлённый/отражённый/выходящий), вращение мышью. Прицельный параметр влияет на точку входа луча
- **Таблица** — эталонные значения для воды (20°C): λ, цвет, n, i₀, r₀, θ₁. Клик по строке загружает параметры в симуляцию

**Живой расчёт:** для текущих параметров выводятся n(λ), угол падения i, угол преломления r, угол отклонения D, угол радуги θ. При h/R, близком к значению Декарта, подсвечивается маркер «Декартов луч».

### 2. Разложение белого света по длинам волн (`SpectrumTable`)

Зависимость показателя преломления n от длины волны λ согласно формуле Коши.

**Интерактивные элементы:**
- Пресеты материалов: вода, крон (стекло), флинт (стекло), алмаз
- Ручной ввод коэффициентов A, B, C — при редактировании пресет сбрасывается
- Ползунок произвольной длины волны λ с маркером на графике

**График n(λ):**
- SVG-диаграмма: кривая n(λ) для 380–780 нм, спектральная полоса под осью X, маркер выбранной λ
- Сетка с подписями n и λ
- Защита от деления на ноль при B=C=0 (все n равны) — кривая остаётся видимой

**Эталонная таблица (сворачиваемая):** для воды (20°C) — λ, цвет, эталонный n, текущий n для сравнения.

### 3. Углы отклонения и распределение цветов (`AngleDeviation`)

Расчёт углов Декарта (минимального отклонения) для радуг разного порядка.

**Интерактивные элементы:**
- Ползунок показателя преломления n (1.30–1.60, шаг 0.0001) — автоматически подбирает ближайшую эталонную λ
- Ползунок числа внутренних отражений k (1–3: первичная / вторичная / третичная радуга)
- Кнопки выбора цвета (λ) — устанавливают эталонное n для воды
- **Zoom-панель:** 1×, 2×, 3×, 4×, 5×, 10×, 15×, 20×, 30× — фокусирует полярную диаграмму на узком диапазоне вокруг угла Декарта для выбранного k. На 30× видимый диапазон ≈ 1.8° — хорошо видны малые смещения точек при изменении n

**Полярная диаграмма:**
- Наблюдатель в центре, противосолнечное направление — вверх, солнце — вниз
- Концентрические круги с подписями градусов (шаг авто-подбирается под zoom)
- Цветные точки (r=10) — эталонные углы для воды
- Белые обводки — углы для текущего n с ползунка
- Реперные кольца: первичная (I) и вторичная (II) радуги — всегда видны полупрозрачными, когда не являются активным k

**Линейная шкала (под описанием):**
- Три горизонтальные линии: I (первичная), II (вторичная), k (выбранный порядок)
- Цветные точки = эталон (вода), белые обводки = текущее n
- При n ≥ 1.4 шаг меток оси X = 20°; при диапазоне > 50° шаг = 10°; иначе 5° или 2°
- Смещение обводок при движении ползунка n сразу показывает, как меняются углы

**Живой расчёт:** n, k, i₀ (угол Декарта), r₀, D_min, θ_радуги, текущий диапазон zoom.

**Эталонные таблицы (сворачиваемые):** первичная и вторичная радуга для воды — цвет, n, θ.

### 4. Кривые интенсивности (`IntensityCurve`)

Зависимость интенсивности рассеянного света от угла θ с учётом френелевских потерь.

**Интерактивные элементы:**
- Ползунок показателя преломления n (1.30–1.55, шаг 0.0005)
- Кнопки выбора цвета (λ) — устанавливают эталонное n для воды
- Чекбоксы: показать вторичную радугу (k=2 отраж.), показать третичную радугу (k=3 отраж.)

**График:**
- SVG-диаграмма: ось X — угол θ от противосолнечной точки, ось Y — интенсивность (%)
- Сплошная белая кривая — первичная радуга
- Пунктирная кривая — вторичная радуга (если включена)
- Мелкий пунктир — третичная радуга (если включена)
- Белые маркеры на пиках, подписи «Первичная» / «Вторичная»
- Сетка: метки интенсивности (0–8%), метки градусов с переменным шагом
  - Диапазон ≤ 20° → шаг 5°
  - Диапазон 20–50° → шаг 10°
  - Диапазон > 50° (с третичной) → шаг 30°

**Живой расчёт:** n, пик I (θ), I_max(I) в %, пик II (θ), отношение I_max(II)/I_max(I).

**Эталонная таблица (сворачиваемая):** θ от 37° до 54°, интенсивности I₁, I₂, I₃ в %.

### 5. Разложение в материале: стеклянная призма (`PrismDemo`)

Полная трассировка луча через треугольную призму по закону Снеллиуса.

**Интерактивные элементы:**
- Ползунок угла при вершине A (20°–85°)
- **Ползунок угла падения i₁** (5°–75°) — управляет наклоном входящего луча относительно нормали к левой грани
  - При i₁ = A/2 луч идёт горизонтально
  - При увеличении — луч рассеивается вниз
  - При уменьшении — луч концентрируется вверх
- Пресеты материалов: вода, крон, флинт, алмаз
- Ручной ввод коэффициентов Коши A, B, C
- Ползунок и кнопки выбора длины волны λ

**SVG-диаграмма:**
- Призма треугольного сечения (полигон, динамически перестраивается под угол A)
- Белая линия — входящий луч, пунктирная нормаль в точке входа
- Для каждой длины волны (7 цветов):
  - Цветная линия внутри призмы — преломлённый луч
  - Цветная линия на выходе — выходящий луч
  - Точка на правой грани — место выхода
- Экран справа — спектральная проекция (градиентный прямоугольник), ширина зависит от дисперсии
- Тонкие цветные линии от точек выхода к экрану

**Живой расчёт:** A, n, i₁, r₁ (угол преломления на входе), i₂' (внутренний угол падения на выходную грань), i₂ (угол выхода), D (полное отклонение), ΔD (дисперсия — разница D между крайними цветами).

**Обработка ошибок:**
- ПВО на входной грани: «Уменьшите i₁»
- ПВО на выходной грани: «Увеличьте A или уменьшите i₁»
- Луч не попадает на выходную грань
- Часть длин волн испытывает ПВО (жёлтое предупреждение)

**Эталонная таблица (сворачиваемая):** для крона, A=60°, i₁=30° — цвет, λ, n, D.

## Физические основы

### Закон Снеллиуса (преломление)

```
n₁ · sin θ₁ = n₂ · sin θ₂
```

На границе воздух–вода: `sin i = n · sin r`, где `i` — угол падения, `r` — угол преломления, `n` — показатель преломления воды относительно воздуха.

В векторной форме (используется в трассировке призмы):

```
d_прел = η · d_пад + (cos θ_прел - η · cos θ_пад) · n
```

где `η = n₁/n₂`, `n` — нормаль к поверхности.

### Формула Коши (дисперсия)

Зависимость показателя преломления от длины волны:

```
n(λ) = A + B/λ² + C/λ⁴
```

где `λ` — длина волны в нанометрах.

| Материал | A      | B (нм²) | C (нм⁴) |
|----------|--------|---------|---------|
| Вода     | 1.324  | 3090    | 0       |
| Крон     | 1.504  | 4430    | 0       |
| Флинт    | 1.715  | 13800   | 0       |
| Алмаз    | 2.410  | 15600   | 0       |

### Луч Декарта (минимальное отклонение)

Для капли с k внутренними отражениями угол минимального отклонения достигается при:

```
cos i₀ = √((n² - 1)/(k² - 1))
```

где `i₀` — угол падения Декарта, `k` — число внутренних отражений + 1 (т.е. для первичной радуги k=2, для вторичной k=3).

Угол отклонения:

```
D = (k-1)·180° + 2i - 2k·r
```

где `r = arcsin(sin i / n)`.

Угол радуги (от противосолнечной точки):

```
θ = { 180° - D,  k = 2 (первичная);  D - 180°,  k ≥ 3 }
```

### Формулы Френеля (интенсивность)

Доля отражённой энергии на границе раздела сред:

```
R_s = (sin(i - r)/sin(i + r))²
R_p = (tan(i - r)/tan(i + r))²
```

Средний коэффициент отражения: `R = (R_s + R_p)/2`

Коэффициент пропускания: `T = 1 - R`

Интенсивность луча после k–1 внутренних отражений:

```
I = T_вход · R^(k-1) · T_выход
```

В силу симметрии `T_вход = T_выход = T`, поэтому:

```
I = T² · R^(k-1)
```

### Преломление в призме

Для призмы с углом при вершине A и углом падения i₁:

1. **Входная грань:** `sin i₁ = n · sin r₁`
2. **Внутренний угол на выходной грани:** `i₂' = A - r₁`
3. **Условие ПВО:** `n · sin i₂' > 1`
4. **Выходная грань:** `n · sin i₂' = sin i₂`
5. **Полное отклонение:** `D = i₁ + i₂ - A`

Минимальное отклонение (симметричный ход, i₁ = i₂, r₁ = A/2):

```
D_min = 2·arcsin(n·sin(A/2)) - A
```

## Навигация по сайту

Сайт — одностраничный лендинг (SPA) с якорной навигацией. Вверху закреплено полупрозрачное меню, секции идут друг за другом при скролле.

### Верхнее меню

| Пункт           | Якорь           | Куда ведёт                     |
|-----------------|-----------------|--------------------------------|
| **О проекте**   | `#about`        | Описание явления и цели моделирования |
| **Возможности** | `#features`     | Сетка из пяти карточек с полным функционалом |
| **Радуга**      | `#rainbow`      | Сравнение первичной и вторичной радуги |
| **Моделирование**| `#simulation`   | SVG-диаграмма дисперсии в призме |

### Порядок секций

1. **Hero** — полноэкранный блок с заголовком «Образование радуги», подзаголовком и двумя кнопками: «Узнать больше» (→ `#about`) и «Возможности» (→ `#features`). Фоновые эффекты: радужное кольцо (conic-gradient), свечение, анимированные капли.
2. **О проекте** (`#about`) — раздел на тёмной подложке. Объяснение физики радуги.
3. **Возможности** (`#features`) — сетка карточек 2×2 (пункты 01–04) и одна центрированная карточка (05). Каждая — с номером, заголовком и описанием.
4. **Первичная и вторичная радуга** (`#rainbow`) — две карточки рядом: тип отражения, угловой радиус, порядок цветов, визуализация спектра.
5. **Моделирование** (`#simulation`) — SVG-диаграмма призмы: белый луч → семь расходящихся лучей → спектральная проекция. Кнопка «Запустить симуляцию» (→ `#simulations`).
6. **Интерактивные симуляции** (`#simulations`) — пять полнофункциональных демо (см. Функционал выше).
7. **Footer** — информация о проекте, ссылки на дизайн-систему SpaceX и shadcn/ui.

### Дизайн-система SpaceX

Лендинг построен по токенам из [awesome-design-md/spacex/DESIGN.md](awesome-design-md/design-md/spacex/DESIGN.md):

- **Цвета:** чёрный канвас (`#000000` / `#0A0A0A`), белый текст, серые разделители (`hairline-dark`). Никаких акцентных цветов в элементах интерфейса.
- **Типографика:** Inter 700, uppercase для заголовков, tracking 0.96–1.6 px, кастомные классы `.display-xxl`, `.display-xl`, `.display-lg`.
- **Кнопки:** ghost outline pill — обводка 1px, border-radius 32px, при hover заливка белым и чёрный текст.
- **Глубина:** без теней — только смена фона и 1px-бордеры.
- **Радужные элементы** (conic-gradient, SVG-спектр, цветные лучи) — как контент симуляций, не в элементах интерфейса.

### shadcn/ui-компоненты

- **Button** — ghost-variant, pill, uppercase, переход hover: белая заливка / чёрный текст
- **Card** — тёмный фон + hairline-бордер

## Примечания по реализации

### Почему Radix NavigationMenu — именованные экспорты

Radix UI экспортирует компоненты NavigationMenu как именованные: `Root`, `List`, `Item`, `Link`. Составная запись через точку (`NavPrimitive.List`) не работает — каждый компонент обёрнут в `forwardRef` отдельно в `navigation-menu.jsx`.

### Кнопки — `type="button"`

Все `<button>` внутри форм и интерактивных панелей имеют атрибут `type="button"`. Без него браузер может интерпретировать кнопку как `type="submit"`, вызывая навигацию/перезагрузку страницы при клике.

### Защита от деления на ноль в SpectrumTable

При B=C=0 все значения n(λ) равны — диапазон nRange = 0. Используется `Math.max(nMax - nMin, 0.001)` для предотвращения NaN в координатах графика.

### SVG viewBox в PrismDemo

viewBox начинается с x=-80 (а не 0) чтобы вместить входящий луч при любых комбинациях угла при вершине и угла падения.

### Three.js в RayTrace3D

Сцена использует `MeshPhysicalMaterial` с прозрачностью 0.18, wireframe-обводку, и орбитальный контроль через сферические координаты (phi clamped 0.3–π/2).

### Шаг меток на осях

Во всех графиках шаг меток подбирается динамически в зависимости от отображаемого диапазона — это предотвращает наслоение текста. Логика реализована через условные операторы и функцию `niceStep()` для полярной диаграммы.
